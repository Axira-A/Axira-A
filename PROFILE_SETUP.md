# Axira-A GitHub Profile

This repository is intentionally built as a self-hosted GitHub Profile README rather than a collection of third-party profile widgets.

## Visual assets

- `assets/banner-v2.webp` — cinematic profile header, compressed for fast README loading.
- `assets/projects-showcase.webp` — project selection panel.
- `assets/tools-showcase.webp` — equipped-tools panel.
- `assets/bonfire-v2.webp` — cinematic footer.
- `assets/divider.svg` — lightweight section divider.
- `assets/activity.svg` — public activity card generated by GitHub Actions.

Legacy animated assets remain in the repository as fallbacks/source material; the live profile uses optimized WebP artwork to keep the first load lightweight.

## Dynamic activity

`.github/workflows/update-profile.yml` runs daily and can also be started manually. It executes `scripts/update_profile.py`, which:

1. fetches repositories owned by `Axira-A` from the GitHub REST API;
2. ignores forks, archived/empty repositories and the profile repository;
3. sorts remaining public repositories by their last push;
4. renders the latest four into `assets/activity.svg`;
5. keeps the existing SVG if the API is unavailable;
6. commits only if the SVG actually changed.

No personal access token is required. The workflow uses the repository-provided `GITHUB_TOKEN`.

## Repository permissions

If the scheduled workflow can read but cannot push the refreshed card, open:

`Settings → Actions → General → Workflow permissions`

and allow **Read and write permissions**.
