# Axira-A Profile — deployment notes

This folder is a ready-to-commit GitHub Profile README for `Axira-A/Axira-A`.

## Files

- `README.md` — the profile shown on GitHub.
- `assets/banner.gif` — self-hosted animated header.
- `assets/bonfire.gif` — self-hosted animated footer.
- `assets/divider.svg` — section divider.
- `assets/activity.svg` — generated public-work card.
- `scripts/update_profile.py` — standard-library generator for `activity.svg`.
- `.github/workflows/update-profile.yml` — daily + manual refresh workflow.

## Deploy

Copy the contents of this folder into the root of the public `Axira-A/Axira-A` repository, then commit and push.

Example from a local clone:

```powershell
git add README.md assets scripts .github/workflows/update-profile.yml
git commit -m "feat: redesign GitHub profile"
git push
```

## First Actions run

After pushing, open the repository's **Actions** tab and run **Update profile activity** once with **Run workflow**. The scheduled workflow also runs daily.

If GitHub Actions cannot push, check:

**Settings → Actions → General → Workflow permissions → Read and write permissions**

The workflow already declares `contents: write`; repository policy must also allow it.

## Design rules

The profile intentionally avoids remote stat/typing services. Animated visual assets are stored in the profile repository, while the activity card is generated by the repository's own workflow. This keeps the profile usable even if third-party README services disappear.

Replace `assets/banner.gif` or `assets/bonfire.gif` at any time without touching the README, as long as the filenames stay the same.
