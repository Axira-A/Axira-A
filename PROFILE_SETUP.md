# Axira-A GitHub Profile — Vector UI v3

This profile is designed for the special GitHub profile repository `Axira-A/Axira-A`.

## What changed in v3

The old raster-heavy layout was replaced by a self-hosted vector UI system:

- `assets/hero.svg` — sharp animated header, built from SVG shapes and native SMIL motion.
- four `assets/project-*.svg` files — independent clickable project cards, so the project section never depends on one giant poster image.
- `assets/tools.svg` — eight visible tool slots with local vector icons.
- `assets/forge.svg` — generated from `profile-status.json`.
- `assets/activity.svg` — generated from the GitHub REST API.
- `assets/footer.svg` — lightweight animated bonfire footer.
- `scripts/build_visuals.py` — reproducibly rebuilds the static visual system.
- `scripts/update_profile.py` — regenerates dynamic status/activity cards.
- `scripts/check_profile.py` — rejects missing resources, malformed SVG, accidental raster regressions, and invalid status data.

The primary README UI no longer uses GIF/WebP/PNG art. This keeps typography and linework sharp at every GitHub zoom level and drastically reduces repository asset weight.

## Deploy

Copy the contents of this package to the root of `Axira-A/Axira-A`, then commit and push:

```bash
git add README.md profile-status.json assets scripts .github

git commit -m "feat(profile): vector UI v3"

git push
```

Then open **Actions → Update profile cards → Run workflow** once. The repository's default `GITHUB_TOKEN` is sufficient for public repository activity.

If the workflow cannot push, open:

**Settings → Actions → General → Workflow permissions → Read and write permissions**

## Updating current development focus

Edit only `profile-status.json` for normal status changes. Example:

```json
{
  "updated": "2026-09-11",
  "focus": [
    {
      "project": "MaplesAdventure",
      "status": "ACTIVE BUILD",
      "detail": "combat feel · encounters · bosses · world design · animation"
    }
  ]
}
```

A push that changes this file automatically regenerates `assets/forge.svg`.

## Updating the visual system

Static SVG components are generated by:

```bash
python scripts/build_visuals.py
```

Editing and pushing `scripts/build_visuals.py` also triggers **Rebuild profile visuals**, which commits generated SVG changes only when their bytes changed.

## Dynamic repository activity

`Update profile cards` runs daily and can also be run manually. It:

1. Reads public owner repositories from the GitHub REST API.
2. Ignores forks, archived repositories, empty repositories, and the profile repository itself.
3. Renders the four most recently pushed repositories into `assets/activity.svg`.
4. Commits only when generated output changes.

If the GitHub API is temporarily unavailable, the previous `activity.svg` stays intact.

## External services

The core page does **not** depend on GitHub Readme Stats, typing services, image hosting, or remote icon CDNs. A few small `shields.io` badges in the header are decorative enhancement only; if they fail, the main profile remains complete.

## Validation

Run locally before pushing:

```bash
python scripts/check_profile.py
python -m py_compile scripts/update_profile.py scripts/build_visuals.py scripts/check_profile.py
```

The `Validate profile` GitHub Action runs the same checks on pushes and pull requests.
